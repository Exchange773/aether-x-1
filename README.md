Aether-x (core.go) is a personal AI research project. 
The main goal for this project is to develop an AI agent to help cybersecurity proffessionals map attack surface, detect threats and respond to exploits autonomously in real time.
core.go engine uses three internet search engines (censys, fofa, shodan) to autonomously map attack surface and find vulnerable public facing hosts at risk.
Uses multiple communication channels to help cybersecurity proffessionals (blue teams) communicate with the engine and send control commands
It uses duo model AI brain for more sophisticated decision making.
The project will help cybersecurity proffessionals to catch and stop threats before they even occur!
